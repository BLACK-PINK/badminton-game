# 🏸 Badminton Game (배드민턴 게임)

간단한 2D 배드민턴 게임 기획서

## 1. 개요
- **장르**: 2D 스포츠 / 아케이드
- **플랫폼**: 웹 (HTML5 Canvas, JavaScript) — 추후 모바일 확장 가능
- **플레이 인원**: 1인 (vs AI) / 2인 (로컬 대전)
- **한 판 시간**: 약 3~5분

## 2. 핵심 재미
- 셔틀콕 낙하 위치를 읽고 타이밍 맞춰 치는 쾌감
- 클리어(높게 보내기), 드롭(네트 앞 떨구기), 스매시(강하게 내리꽂기)의 전략적 선택

## 3. 게임 규칙
- 21점 선취, 랠리 포인트제 (랠리에서 이기면 서브 여부와 관계없이 1점)
- 셔틀콕이 상대 코트 바닥에 닿으면 득점, 네트에 걸리거나 코트 밖으로 나가면 상대 득점
- 3세트 2선승 (옵션: 단판 11점)

## 4. 조작
| 동작 | P1 | P2 |
|---|---|---|
| 이동 | A / D | ← / → |
| 점프 | W | ↑ |
| 스윙(클리어) | Space | Enter |
| 스매시 | 점프 중 스윙 | 점프 중 스윙 |
| 드롭 | S + 스윙 | ↓ + 스윙 |

모바일: 좌측 가상 패드(이동/점프), 우측 스윙 버튼

## 5. 게임 시스템
- **물리**: 셔틀콕은 중력 + 공기저항(감속)이 적용되어 뒤로 갈수록 빠르게 떨어지는 궤적
- **타격 판정**: 라켓 히트박스와 셔틀콕이 겹치는 순간 스윙 → 타이밍에 따라 파워/방향 결정
- **AI 난이도**: 쉬움 / 보통 / 어려움 (반응속도, 예측 정확도, 스매시 빈도 차이)
- **서브**: 대각선 서브 없이 단순화 (서버가 Space로 발사)

## 6. 화면 구성
1. 타이틀 (1인/2인, 난이도 선택)
2. 게임 화면 (코트, 네트, 점수판, 세트 표시)
3. 결과 화면 (승패, 다시하기)

## 7. 아트 / 사운드
- 심플한 픽셀 or 플랫 스타일 캐릭터, 실내 체육관 배경
- 효과음: 타격음, 스매시, 득점, 세트 종료 / 경쾌한 BGM

## 8. 개발 로드맵
| 단계 | 내용 |
|---|---|
| M1 | 코트/네트/캐릭터 이동·점프 |
| M2 | 셔틀콕 물리 + 타격 판정 |
| M3 | 점수/서브/세트 규칙 |
| M4 | AI 상대 |
| M5 | UI, 사운드, 모바일 지원 |
| M6 | 밸런싱 & 배포 (GitHub Pages) |

## 9. 향후 아이디어
- 온라인 대전, 캐릭터/라켓 커스터마이징, 토너먼트 모드, 복식
